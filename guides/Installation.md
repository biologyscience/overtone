# 🛠️ Install the app

- Head to the [latest release](https://github.com/biologyscience/overtone/releases)
- Open the **Assets**
- Download the **.zip** corresponding to your OS
  - darwin = MacOS
  - linux = Linux
  - win32 = Windows
- You will see only one folder inside the zip. Extract it and open the executable inside that folder. *You can rename the main folder if you'd like*
- Enjoy 🥳

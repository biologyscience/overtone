# 🛠️ Install the app

- Head to the [latest release](https://github.com/biologyscience/overtone/releases)
- Choose the correct file corresponding to your OS from the **Assets** and download it

| Your OS | Installer *(Recommended)* | Extractable     |
| :------ | ----------------------: | --------------: |
| Windows | <...>-win.exe           | <...>-win.zip   |
| Linux   | <...>-linux.AppImage    | <...>-linux.zip |
| MacOS   | <...>-mac.dmg           | <...>-mac.zip   |

- Enjoy 🥳
